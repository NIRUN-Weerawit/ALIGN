# DistilBERT task-text conditioning

New `scripts/run_intention_ablation.py --use-task-text` runs default to
`--text-encoder-type distilbert`. The general trainer also accepts
`--use-task-text` as an alias for `--use-text`, with the same new default.

The path is instruction → pretrained WordPiece tokenizer → frozen DistilBERT
→ final-layer 768-D CLS feature → trainable `--text-dim` projection → learned
additive action-head conditioning. The transformer stays in evaluation mode
during policy training. Its weights receive no action gradients. Projection
and action conditioning are trained jointly with the policy. As in the prior
bag baseline, the head's additive text projection starts at zero.

This uses pretrained contextual language features rather than a fixed list of
words extracted from the training task labels. Previously unseen instruction
strings can be encoded through subwords; successful control of novel tasks or
paraphrases still requires separate evaluation.

The design is motivated by OpenVLA Appendix E's language-conditioned Diffusion
Policy baseline:
https://arxiv.org/html/2406.09246v3#A5
Our explicit pooling choice is the final-layer CLS feature; we do not claim
every detail of the DROID/OpenVLA baseline is reproduced.

## Train against the existing ViT-B baseline

```bash
python scripts/run_intention_ablation.py \
  --data data/libero_goal.h5 --cache data/libero_goal.dinov2 \
  --vision-backbone dinov2_vitb14 --raw-dim 768 \
  --use-task-text --text-encoder-type distilbert \
  --text-model-name distilbert/distilbert-base-uncased --text-max-length 128 \
  --text-dim 128 --variants intent_memory no_intent_no_memory \
  --output checkpoints/piper_text_distilbert_cp4 \
  --epochs 300 --lr 0.0003 --batch-size 32 --micro-batch-size 8 \
  --compressed-dim 4 --head-d-model 64 --chunk-size 4 \
  --temporal-sampling episode --supervision-points 16 --num-workers 0 --seed 42
```

For ViT-L, use `--vision-backbone dinov2_vitl14 --raw-dim 1024` and its separately
generated cache. That cache is not generated by this change.

## Checkpoints, offline use, and legacy runs

- Saved configs include encoder type, model name, revision, maximum sequence
  length and projection width. Evaluation reconstructs the selected encoder.
- All frozen DistilBERT weights are included in policy checkpoints; this adds
  approximately 266 MB in FP32. Optimizer state excludes the frozen backbone.
- The initial model/tokenizer load uses Hugging Face and may download assets.
  For offline execution, prefetch the model and tokenizer and set
  `--text-model-name /path/to/local/pretrained-directory` (or use the HF cache
  with `HF_HUB_OFFLINE=1`). Saved model paths must be available at evaluation.
  `--text-model-revision` can pin a Hugging Face commit instead of `main`.
- The encoder retains at most 1,024 detached sentence features on CPU. Cached
  features are projected again on each call, so projection gradients remain
  current. The cache is transient and cleared on state-dict loading.
- Existing bag-of-words checkpoint loading is unchanged. To reproduce or resume
  those training runs, explicitly pass `--text-encoder-type bag` in the ablation
  trainer and preserve their other settings. Switching a resumed run to
  DistilBERT is rejected; use a new output directory.

No policy training or simulator evaluations are launched by adding this support.
